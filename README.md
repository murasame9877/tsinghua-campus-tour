# 清华大学校园讲解互动地图

一款面向 iPad 的清华大学校园讲解互动地图应用。点击地图上的建筑标记，即可查看建筑信息、历史背景和分级讲解词（标准/深度/趣味），支持路线规划、分类筛选、搜索和开发者模式。

## 功能特性

- 🗺️ **交互式地图**：高德瓦片底图（卫星图 + 道路标注可切换），OSM 精确坐标
- 📍 **70+ 建筑标记**：历史建筑、教学科研、图书馆、食堂、体育场馆、自然景观等分类
- 📖 **三级讲解词**：每个建筑配标准/深度/趣味三版讲解
- 🏛️ **8 条游览路线**：经典路线、自然之旅、学术之旅及红色主题路线
- 🔍 **搜索与筛选**：按名称搜索、按分类筛选
- 📋 **建筑列表侧栏**：快速定位建筑
- 🔧 **开发者模式**：拖拽标记、编辑信息、上传图片、新增建筑（数据存 localStorage）

## 快速使用

### 在线版（需网络）

直接用浏览器打开 `index.html`（需同目录下的 `leaflet.css`、`leaflet.js`、`images/` 等资源）。

### 离线版（推荐 iPad）

打开 `tsinghua_tour.html`（已将 Leaflet 内联，单文件可独立运行）。

> 高德地图瓦片需联网加载（国内速度快），无网络时底图为空。

## 文件说明

| 文件/目录 | 说明 |
|-----------|------|
| `index.html` | 主源代码（开发/修改用） |
| `tsinghua_tour.html` | 离线单文件版（Leaflet 已内联） |
| `leaflet.css` / `leaflet.js` | Leaflet 1.9.4 库 |
| `images/` | 建筑图片 |
| `extract_tsinghua.py` | 从 OSM PBF 提取清华建筑坐标的脚本 |
| `download_tiles.js` | 下载高德瓦片脚本 |
| `fix_images.js` | 批量设置建筑图片路径脚本 |

## 技术栈

- Leaflet.js 交互地图
- 高德地图瓦片（GCJ-02 坐标 + WGS-84 转换）
- OpenStreetMap 数据（建筑坐标）
- 纯前端，无后端依赖

## 使用许可

仅供个人学习与校内讲解使用。
